# HALO 系统数据对照手册

## 物理层结构（从内向外）

```
半径 ↑    层 4 [密集齿] ← 网络 ✅ 可旋转
          层 3 [配对齿] ← 装饰（未用） ✅ 可旋转
          层 2 [环]     ← 内存 ❌ 实心不可旋
          层 1 [稀疏齿] ← CPU ✅ 可旋转
半径 ↓    层 0 [光晕]   ← 装饰（纯色）❌ 实心不可旋
```

核心：**齿状环可显示旋转，实心环不可**。数据层的分配已避开此坑。

## 三环 × 三维度

| 层 | 硬件 | 形状 | 颜色 | 第二维度 | 第三维度 |
|----|------|------|------|---------|---------|
| **层1** | CPU | 稀疏齿 ✅可旋 | 使用率: 蓝绿↔红 | 温度→脉冲速度↑ | 负载→旋转速度↑ |
| **层2** | 内存 | 实心环 ❌不可旋 | 使用率: 绿↔紫 | 使用率→闪烁亮度↑ | — |
| **层4** | 网络 | 密集齿 ✅可旋 | 下行: 翡↔金 | 上行→脉冲速度↑ | 吞吐→旋转速度↑ |
| 层0 | — | 光晕 ❌ | 单色（纯装饰） | — | — |
| 层3 | — | 配对齿 ✅可旋 | 单色（纯装饰） | — | — |

## 逐层详细映射

### 层 1 — 稀疏齿 (CPU) ✅可旋转
| 系统数据 | 视觉维度 | 映射公式 | 表现 |
|---------|---------|---------|------|
| CPU 使用率 0→100% | 颜色（插值） | `cpuMix = CPU%/100` | `#2a6e7e` → `#c04040` |
| CPU 温度 35→90°C | 脉冲速度 | `cpuPulse = 0.5 + tempFactor×2.5` | 冷→平静呼吸，热→急促搏动 |
| 系统负载 0→3.0+ | 旋转速度 | `cpuRotSpd = 0.3 + loadFactor×2.7` | 闲→慢转，忙→快转 |

### 层 2 — 环 (内存) ❌不可旋转
| 系统数据 | 视觉维度 | 映射公式 | 表现 |
|---------|---------|---------|------|
| 内存使用率 0→100% | 颜色（插值） | `memMix = Mem%/100` | `#3a9a6a` → `#b058d0` |
| 同上 | 闪烁亮度 | `memBright = 0.3 + memMix×1.2` | 空闲→暗淡，满载→亮闪 |

### 层 4 — 密集齿 (网络) ✅可旋转
| 系统数据 | 视觉维度 | 映射公式 | 表现 |
|---------|---------|---------|------|
| 下行速率 0→5MB/s+ | 颜色（插值） | `netMix = Down/5MB` | `#4a8a7a` → `#d0a050` |
| 上行速率 0→5MB/s+ | 脉冲速度 | `netPulse = 0.5 + upFactor×2.5` | 无上传→平静，上传→躁动 |
| 上下行总量 | 旋转速度 | `netRotSpd = 0.5 + totalFactor×2.5` | 静→缓转，跑流量→快转 |

## 颜色配置对照（调色盘面板）

| UI 名称 | 层 | 配置键 | 默认值 |
|---------|----|--------|-------|
| 光晕 | 层0 | `color0` | `#8fb3a6` |
| 稀疏 (CPU) | 层1 | `color1Start` / `color1End` | `#2a6e7e` → `#c04040` |
| 环 (内存) | 层2 | `color2Start` / `color2End` | `#3a9a6a` → `#b058d0` |
| 配对 | 层3 | `color3` | `#d6ece4` |
| 密集 (网络) | 层4 | `color4Start` / `color4End` | `#4a8a7a` → `#d0a050` |

双端色：起始色 = 低负载/空闲，终止色 = 高负载/繁忙。

## 快速测试清单
```
□ CPU 满载 → 层1 变红、快转
□ CPU 空闲 → 层1 蓝绿、慢转  
□ 内存满载 → 层2 变紫、变亮
□ 内存空闲 → 层2 暗绿
□ 下载中   → 层4 金色、剧烈搏动
□ 断网     → 层4 暗翡、平静
□ 面板调色 → 改色实时生效
```
